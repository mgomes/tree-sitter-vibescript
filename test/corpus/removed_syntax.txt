================
Lambda literals are removed
:error
================

f = -> { 1 }

---



================
Parameterized lambda literals are removed
:error
================

f = ->(a, b) { a + b }

---



================
Do end lambda literals are removed
:error
================

f = ->(n) do
  n * 2
end

---



================
Destructured lambda literals are removed
:error
================

f = ->((key, value)) { key }

---



================
Block capture parameters are removed
:error
================

def f(&blk)
  1
end

---



================
Block forwarding arguments are removed
:error
================

f(&blk)

---



================
Symbol to proc arguments are removed
:error
================

items.map(&:upcase)
